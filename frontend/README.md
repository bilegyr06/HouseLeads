# HomeLeads Frontend

This folder contains the Vite + React single-page app for HomeLeads. The frontend collects tenant lead information in a guided form, submits it to the FastAPI backend, and shows a confirmation screen after submission.

For the full repository overview, setup instructions, API documentation, and deployment notes, see the root [README.md](../README.md).

## Available Scripts

- `npm install` installs dependencies.
- `npm run dev` starts the development server.
- `npm run build` creates a production build.
- `npm run lint` runs ESLint.
